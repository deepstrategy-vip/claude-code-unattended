# 实施与验收状态

## 本轮目标

减少离席时的例行提问、结尾征询和残留权限等待。发布模式：分支实现、测试、PR；必须取得匹配 PR 当前完整头 SHA 的 Claude 复查通过评论后才可 squash 合并与安装。

## 已完成与设计决定

- 调研见 [RESEARCH.md](RESEARCH.md)：官方协议、社区源码、本机 HID 测量及产品验证缺口分别标明。
- 三百秒本机输入空闲门控，配置未知时不介入；显式 away/off 模式与环境覆盖。
- 保留原始工具输入的低风险自动答案；高风险提问/计划与所有残余权限延期，不新增授权。
- 最后一行窄范围 Stop 检测，active guard、指纹去重、持久会话预算及并发锁。
- 全部新旧自动决定先写结构化私有审计，永不自动清理；无原始命令/问题/答案文本。
- 安装器管理多事件、配置、备份；保留用户规则块外原文，通知/风格/超时仅显式 opt-in。

## 验证与已知限制

本轮用临时配置目录验证协议与安装，不改真实用户配置。Python 3.9 与 3.14 各通过 48 个 unittest；CI 结果以 PR 检查为准。测试包括检测到人在场时不介入、未知/故障 fail-open、并发 Stop 预算、审计失败、符号链接拒绝、安装幂等和规则后缀保留。

尚未做真实 Desktop/手机端到端测试；未运行付费模型请求。HID 只代表本机输入，事件只采样一次；已有弹窗不会因之后离席自动恢复。风险和文字识别是启发式策略；拒绝 ExitPlanMode 后仍只读；第三方/MCP 原生授权与系统权限不保证可被 hook 接管。

## 待办与下一步

- PR 通过 CI 后等待当前头对应的外部 Claude 复查，任何新提交都重新等待。
- 复查通过前不安装真实配置；通过后按授权流程合并、更新安装副本、安装并比对自写规则后缀。
- 自然使用中观察真实 Desktop/Remote Control 问题、误判和漏判；以审计与任务结果评估，不把协议测试等同产品验收。
- 回滚：`python3 install.py --uninstall` 可移除管理项，或恢复安装备份；保留审计至少 186 天。通知/风格/超时偏好卸载保留，必要时手动恢复对应备份。
